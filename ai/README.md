# NPC 판단

`npc.py`는 `python main.py`로 실행한 게임에서 CPU의 선언과 GREED! 판단을 담당한다.
브라우저는 `/api/npc`에 관측 가능한 정보만 보낸다. 정적 파일 서버처럼 API가 없는
환경에서는 기존 브라우저 판단으로 이어진다.

- 탐욕꾼(`hat`): 큰 선언 보상에 가장 강하게 끌린다.
- 속삭임(`hood`): 보통은 신중하지만 점수 열세·손실이 쌓이면 만회를 노린다.
- 집행관(`monocle`): 둘 사이의 성향이며 보상이 큰 적발 기회를 탐낸다.

남은 카드 조합으로 합계의 가능성을 계산한 뒤, 위험·체력 손실에 대한 평가를
탐욕 성향에 따라 편향시킨다. 포인트를 즉시 받는 유혹, 뒤처진 점수, 빚,
최근 손실과 연속 보상이 선택을 바꾼다. 무조건 최대 숫자를 부르거나 정확한 합계를
아는 AI가 아니다. 불확실한 적발에서 오판할 수 있고, 체력이 낮으면 두려움도 커진다.

`PERSONALITIES`의 `greed`와 `caution`으로 기본 성향을 조정한다.
감정 상태는 각 플레이어의 `npcMomentum`, `npcFrustration`에 저장하며 라운드마다
완화된다. 새 게임에서는 초기화한다. 서버는 감정/게임 상태를 별도로 저장하지 않는다.

`Observation`에는 자기 실제 카드와 실제 전체 합계 필드가 없다.
보이는 생존자 카드와 이미 공개된 숫자를 바탕으로 가능한 나머지 조합만 사용한다.
선언은 직전보다 높아야 하고, 두 배 서약은 기본 보상 30P 이상에서만 허용한다.

검증:

```text
python tests/test_npc.py
python tests/npc_integration.py
```
